# TEST — Technology & Innovation Website

A modern multi-page website built with **HTML, CSS, and JavaScript only** (no frameworks, no build step).

## Features

- 🔐 **Working auth system** — sign up, log in, log out, and password reset, all stored in the browser via `localStorage`
- 👤 **User chip** in the navbar shows the logged-in user
- 📝 **Validation** on every form (email format, password length, matching passwords, etc.)
- 🔥 **Toast notifications** for success/error feedback
- 💪 **Live password strength meter** on sign up
- 👁️ **Show/hide password** toggles
- 📱 **Fully responsive** with a mobile hamburger menu
- 🌙 Sleek dark "tech" theme with gradient accents
- ✍️ Uses the exact Google Fonts and Font Awesome icons requested

## How to run

Just open `index.html` in your browser.


## Try the auth

1. Go to **Sign Up** and create an account (any email + 6-char password).
2. You'll be logged in automatically — notice your name in the navbar.
3. Log out, then go to **Login** and sign back in.
4. Try **Forgot Password** — enter your signup email; a 6-digit demo code appears on screen. Enter it plus a new password.

> Accounts are stored in your browser's `localStorage`, so they persist across refreshes but never leave your device.
